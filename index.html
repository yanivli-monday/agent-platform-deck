02R&R · Roles & Responsibilities
Platform Team Template, routing, notifications
  • The template. Defines the UI shell — the slot Persona Teams plug their card into.
  • Aggregation & routing. Collects pending actions from every agent in one place, and routes the user's answers back to the right agent.
  • Notifications. The infrastructure that pings users when their attention is needed.
Persona Teams Tools, logic, UI
  • Tools. Define the tools the agent uses — per the Platform's interface.
  • Logic. All business logic — e.g., to send an email, write a Send Email tool.

The boundary, at a glance

Across every touchpoint the pattern is identical — Platform ships the primitives, Persona ships the meaning.

Touchpoint Platform owns Persona owns
Home — Discovery Carousel template, content ingestion Copy, imagery, MF payload Persona · targeting Growth
Home — HITL Lifecycle (Approve / Reject / Feedback) Schema, business logic, presentation MF
Reasoning & Trust Trust UI framework, source registry, progress states Scan list, reasoning copy, source-to-context mapping
Creation & Editing Schema engine, Simulation, Activity Log, Scheduler Activation config, tools, permissions, auth, test inputs
Agent Page Edit access, ledger, scoped HITL, outcome endpoint UI layer — within Platform's guidelines
Triggers Cron infrastructure, run endpoint, run input schema Run entry point(s)
→

Platform = rails. Schemas, lifecycle, layout slots, history, simulation.   ·   Persona = payload. Tools, business logic, copy, outcome UI, governance of their domain.

Milestones · Build Plan

Phase 1 · Foundation M1 → M5
M1

Skeleton agents (in-memory)

  • Agents without tools — ingest external context & reason on top.
  • Temporary UI to fetch, create & run end-to-end.
  • Session traces in langsmith. Agents are in-memory only — no DB yet.
M2

Tools + DB persistence

  • Agents gain the ability to call tools (tools must already be authenticated).
  • Agents are now persisted in a database.
M3

Agents page & chat shell

  • Agents pageLists all agents · click → agent home (2 placeholder tabs) · initial chat entry point.
  • ChatCreate / edit settings in the modal (no chat yet) · Home widget opens the modal.
M4

Agent home + read-only chat

  • Persona Teams build their agent's home page.
  • Read-only chat (session history) — text only.
M5

Live chat + tool UI

  • Chat input to converse with the agent (agent doesn't yet edit its own settings).
  • Persona Teams ship UI for their tools (not connected yet). TBD if useful before the UI can actually be used.
